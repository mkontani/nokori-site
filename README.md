# nokori — site

[nokori（のこり）](https://mkontani.github.io/nokori-site/) のランディングページとプライバシーポリシーを配信する静的サイトです。

> 3秒で記録できる、静かな家計簿。

- `index.html` — ランディングページ
- `privacy.html` — プライバシーポリシー（日本語 / English）
- GitHub Pages（main ブランチ / ルート）で公開

アプリ本体のソースは別の非公開リポジトリで管理しています。お問い合わせは [Issues](https://github.com/mkontani/nokori-site/issues) へ。
